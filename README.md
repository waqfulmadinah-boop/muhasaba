# মুহাসাবত্র

দৈনন্দিন কাজের হিসাব রাখার সুন্দর ও সমৃদ্ধ অ্যাপ্লিকেশন।

## ফিচারসমূহ

### মূল ফিচার
- লগইন/রেজিস্ট্রেশন সিস্টেম (JWT Authentication)
- দৈনিক কাজ যোগ, সম্পন্ন চিহ্নিত ও মুছে ফেলা
- ড্যাশবোর্ডে কাজের পারসেন্টেজ ও মোটিভেশনাল মন্তব্য
- নোট/ডায়েরি লেখার ব্যবস্থা

### নতুন ফিচার
- **ডার্ক মোড** - লাইট ও ডার্ক থিম টগল
- **অ্যানিমেশন** - সুন্দর CSS অ্যানিমেশন ও ট্রানজিশন
- **ক্যাটাগরি** - কাজকে বিভিন্ন ক্যাটাগরিতে ভাগ করুন (কাজ, পড়াশোনা, স্বাস্থ্য, ব্যক্তিগত)
- **প্রায়োরিটি** - কম, মাঝারি, বেশি প্রায়োরিটি নির্ধারণ
- **স্ট্রিক কাউন্টার** - ধারাবাহিক দিন ট্র্যাক করুন
- **ক্যালেন্ডার ভিউ** - মাসিক ক্যালেন্ডারে কাজের অবস্থা দেখুন
- **ব্যাজ/অ্যাচিভমেন্ট** - ১০টি ব্যাজ অর্জন করুন
- **সার্চ ও ফিল্টার** - কাজ ও নোট খুঁজুন
- **প্রোফাইল সেটিংস** - নাম ও পাসওয়ার্ড পরিবর্তন
- **রিসপন্সিভ ডিজাইন** - মোবাইল ও ডেস্কটপে সুন্দর

## চালু করার নিয়ম

```bash
# Backend চালু করুন
cd server
npm install
npm start

# Frontend চালু করুন (আলাদা টার্মিনাল)
cd client
npm install
npm start
```

ব্রাউজারে খুলুন: http://localhost:3000

## প্রয়ুক্তি

- React 18 + Vite
- Express.js
- NeDB (Lightweight Database)
- JWT Authentication
- CSS3 Animations

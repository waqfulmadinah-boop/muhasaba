# মুহাসাবত্র

দৈনন্দিন কাজের হিসাব রাখার অ্যাপ্লিকেশন।

## ফিচার

- লগইন/রেজিস্ট্রেশন সিস্টেম
- দৈনিক কাজ যোগ, সম্পন্ন চিহ্নিত ও মুছে ফেলা
- ড্যাশবোর্ডে কাজের পারসেন্টেজ
- মোটিভেশনাল মন্তব্য (৫০% এর কম, ৭০%, ৯০%+)
- নোট/ডায়েরি লেখার ব্যবস্থা
- সাপ্তাহিক পারফরম্যান্স চার্ট
- রিফ্রেশে স্বয়ংক্রিয় লগআউট

## চালু করার নিয়ম

```bash
# Backend চালু করুন
cd server
npm install
npm start

# Frontend চালু করুন (আলাদা টার্মিনাল)
cd client
npm install
npm start
```

ব্রাউজারে খুলুন: http://localhost:3000

## প্রয়ুক্তি

- React (Vite)
- Express.js
- NeDB
- JWT Authentication
